# 网络设备零配置部署工具使用说明

## 1. 项目概述

网络设备零配置部署工具(ZTP工具)是一个用于快速部署网络设备的图形界面工具。通过集成DHCP和TFTP服务，该工具可以在设备接入网络时自动分发IP地址并下发配置文件，实现设备的零接触配置。

## 2. 软件功能

- **DHCP服务器**：自动分配IP地址给网络设备
- **TFTP服务器**：提供配置文件下载
- **设备识别**：基于MAC地址或客户端DHCP ID识别设备
- **差异化配置**：为不同设备提供不同配置文件
- **日志记录**：实时显示服务运行状态和设备请求

## 3. 安装与运行

### 3.1 运行环境要求
- Windows操作系统
- 管理员权限（需要使用特权端口67和69）

### 3.2 运行方式
- 直接运行EXE文件

## 4. 基本界面

程序界面由三个主要选项卡组成：
- **网络配置**：配置基本网络服务参数
- **多设备场景**：配置特定设备的映射规则
- **服务日志**：查看服务运行日志

底部控制区域包含服务状态指示器、启动/停止服务按钮和退出按钮。

## 5. 单设备配置模式

当您只需要为所有设备提供相同配置时，可以使用单设备模式。

### 5.1 操作步骤

1. 打开"**网络配置**"选项卡
2. 点击"**自动检测IP**"按钮识别本机IP
3. 确认服务器IP、网关IP和TFTP服务器地址（通常三者相同）
4. 设置DHCP分配的IP地址范围（默认为100-200）
5. 确认TFTP根目录和默认配置文件名（默认为startup.cfg）
6. 点击"**应用网络配置**"保存设置
7. 点击底部"**启动ZTP服务**"按钮启动服务
8. 连接新设备到网络，它将自动获取IP地址和配置文件

### 5.2 默认配置文件说明

程序首次运行时会在TFTP根目录创建`startup.cfg`文件，默认包含以下配置：

```
interface MGE0/0/0
ip address dhcp-alloc

local-user admin class manage
password simple h3c.com
service-type ssh
authorization-attribute user-role network-admin

ssh server enable

line vty 0 63
authentication-mode scheme
user-role network-admin
idle-timeout 0 0
```

您可以根据实际需求修改此文件或者使用你需要的.cfg文件。

## 6. 多设备不同配置场景

当您需要为不同设备提供不同配置文件时，请使用多设备场景。

### 6.1 操作步骤

1. 完成"**网络配置**"选项卡的基本设置
2. 切换到"**多设备场景**"选项卡
3. 选择映射类型：
   - **设备DHCP标识符(Client ID)**: 基于设备的DHCP客户端ID
   - **设备MAC地址**: 基于设备的物理MAC地址
4. 输入设备标识符（Client ID或MAC地址）
5. 指定该设备专用的配置文件名（如device1.cfg）
6. 点击"**添加映射**"按钮
7. 按需重复添加其他设备映射
8. 切换回"**网络配置**"选项卡，点击"**应用网络配置**"
9. 点击底部"**启动ZTP服务**"按钮

### 6.2 配置文件准备

1. 在TFTP根目录中创建各设备对应的配置文件
2. 文件内容应根据设备型号和需求定制
3. 程序首次运行时会自动在tftpboot目录下创建示例配置文件

### 6.3 实际应用场景示例

假设有两台设备，MAC地址分别为 00:11:22:33:44:55 和 AA:BB:CC:DD:EE:FF：
1. 为第一台设备添加映射：标识符=00:11:22:33:44:55，配置文件=device1.cfg
2. 为第二台设备添加映射：标识符=AA:BB:CC:DD:EE:FF，配置文件=device2.cfg
3. 在TFTP根目录创建device1.cfg和device2.cfg文件
4. 启动服务后，设备连接网络时会自动获取对应的配置文件

## 7. 服务日志与监控

1. 当ZTP服务启动后会自动切换到"**服务日志**"选项卡，可以实时查看服务运行状况
2. 日志将显示以下信息：
   - DHCP服务器的请求和响应
   - TFTP文件传输请求
   - 设备标识符识别
   - 配置文件映射情况
   - 错误和警告信息
3. 使用"**清除日志**"按钮可以清空日志内容

## 8. 常见问题和故障排除

### 8.1 端口冲突
如果启动失败提示端口被占用，请确保：
- 关闭可能正在运行的其他DHCP/TFTP服务
- 使用管理员权限运行本程序
- 检查系统服务中是否有占用67/69端口的服务

### 8.2 设备无法获取配置文件
1. 确认TFTP根目录中存在指定的配置文件
2. 检查日志中是否有"映射的配置文件不存在"的错误
3. 验证设备标识符与映射规则是否匹配
4. 确保防火墙未阻止DHCP或TFTP流量

### 8.3 配置文件不生效
1. 确认配置文件语法正确
2. 检查设备型号是否支持所使用的命令
3. 验证设备是否支持ZTP功能

## 9. 注意事项

1. 程序需要以管理员权限运行
2. 启动服务会禁用配置选项卡，需先停止服务才能修改配置
3. 退出程序前请先停止服务，否则可能导致端口无法立即释放
4. 多设备场景下，确保标识符输入格式正确（MAC地址格式或Client ID格式）
5. 在生产环境使用前，建议在测试网络中验证配置生效情况
