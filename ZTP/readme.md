# 网络设备零配置部署工具使用说明 - 更新版

## 1. 项目概述

网络设备零配置部署工具(ZTP工具)是一个用于快速部署网络设备的图形界面工具。通过集成DHCP和TFTP服务，该工具可以在设备接入网络时自动分发IP地址并下发配置文件，实现设备的零接触配置。

## 2. 软件功能

- **DHCP服务器**：自动分配IP地址给网络设备
- **DHCP中继支持**：支持跨网段设备通过DHCP中继获取配置
- **TFTP服务器**：提供配置文件下载
- **设备识别**：基于MAC地址或客户端DHCP ID识别设备
- **差异化配置**：为不同设备提供不同配置文件
- **自定义地址池**：支持自定义DHCP地址池，不受本机网段限制
- **日志记录**：实时显示服务运行状态和设备请求

## 3. 安装与运行

### 3.1 运行环境要求
- Windows操作系统
- 管理员权限（需要使用特权端口67和69）

### 3.2 运行方式
- 直接运行EXE文件

## 4. 基本界面

程序界面由三个主要选项卡组成：
- **网络配置**：配置基本网络服务参数
- **多设备场景**：配置特定设备的映射规则
- **服务日志**：查看服务运行日志

底部控制区域包含服务状态指示器、启动/停止服务按钮和退出按钮。服务状态通过按钮颜色直观显示：绿色表示可启动，红色表示可停止。

## 5. 单设备配置模式

### 5.1 操作步骤

1. 打开"**网络配置**"选项卡
2. 点击"**自动检测IP**"按钮识别本机IP
3. 设置服务器IP、网关IP和TFTP服务器地址
4. **重要**：设置DHCP分配的IP地址范围，可以根据实际需求设置任意网段
5. 确认TFTP根目录和默认配置文件名（默认为startup.cfg）
6. 点击"**应用网络配置**"保存设置
7. 点击底部"**启动ZTP服务**"按钮启动服务
8. 连接新设备到网络，它将自动获取IP地址和配置文件

## 6. 多设备不同配置场景

操作步骤与原来相同，不再重复。

## 7. DHCP中继环境配置

### 7.1 中继环境说明

DHCP中继允许跨网段设备通过中继代理获取IP地址和配置。例如：
- ZTP服务器位于192.168.167.0/24网段
- 设备位于10.1.1.0/24网段
- 中继代理位于两个网段之间

### 7.2 中继环境配置步骤

1. 在"**网络配置**"选项卡中，按常规设置服务器参数
2. **重要**：设置DHCP地址池为客户端所在网段的地址范围（如10.1.1.100-10.1.1.200）
3. 确保TFTP服务器地址设置为ZTP服务器的IP地址
4. 配置中继代理设备：
   - 在客户端所在网段接口上启用dhcp relay server-address指向ZTP服务器
   - 确保中继代理与ZTP服务器之间的路由正常
5. 点击"**应用网络配置**"和"**启动ZTP服务**"

### 7.3 中继环境注意事项

1. 确保客户端所在网段与ZTP服务器之间有双向路由
2. 中继代理需要正确转发DHCP和TFTP流量
3. 防火墙规则需要允许UDP 67/68（DHCP）和UDP 69（TFTP）端口
4. 日志中会显示"通过中继代理发送DHCP OFFER/ACK"等信息

## 8. 服务日志与监控

1. 当ZTP服务启动后会自动切换到"**服务日志**"选项卡，可以实时查看服务运行状况
2. 日志将显示以下信息：
   - DHCP服务器的请求和响应
   - 中继请求的识别和处理
   - TFTP文件传输请求
   - 设备标识符识别
   - 配置文件映射情况
   - 错误和警告信息
3. 使用"**清除日志**"按钮可以清空日志内容

## 9. 常见问题和故障排除

### 9.1 端口冲突
如果启动失败提示端口被占用，请确保：
- 关闭可能正在运行的其他DHCP/TFTP服务
- 使用管理员权限运行本程序
- 检查系统服务中是否有占用67/69端口的服务

### 9.2 设备无法获取配置文件
1. 确认TFTP根目录中存在指定的配置文件
2. 检查日志中是否有"映射的配置文件不存在"的错误
3. 验证设备标识符与映射规则是否匹配
4. 确保防火墙未阻止DHCP或TFTP流量

### 9.3 中继环境问题排查
1. 检查中继代理配置是否正确（IP helper-address配置）
2. 验证客户端网段与ZTP服务器之间的路由
3. 检查日志中是否有"通过中继代理发送"信息
4. 确认地址池设置是否位于客户端所在网段

### 9.4 配置文件不生效
1. 确认配置文件语法正确
2. 检查设备型号是否支持所使用的命令
3. 验证设备是否支持ZTP功能

## 10. 注意事项

1. 程序需要以管理员权限运行
2. 启动服务会禁用配置选项卡，需先停止服务才能修改配置
3. 退出程序前请先停止服务，否则可能导致端口无法立即释放
4. 多设备场景下，确保标识符输入格式正确（MAC地址格式或Client ID格式）
5. 在生产环境使用前，建议在测试网络中验证配置生效情况
6. 自定义DHCP地址池可以设置为任意网段，不再局限于ZTP服务器所在网段
